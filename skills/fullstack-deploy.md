> **触发条件**：需要容器化部署或配置 CI/CD Pipeline 时。

## Step 2: Dockerfile 生成

### 设计原则

1. **多阶段构建**：分离构建阶段和运行阶段，减小镜像体积
2. **非 root 用户**：以非特权用户运行应用
3. **精确版本**：基础镜像和依赖锁定版本（不用 `latest`）
4. **层级缓存**：先复制依赖文件（利用 Docker layer cache），再复制源码

### 模板 — Python / FastAPI

```dockerfile
# ============================================================
# Stage 1: Build
# ============================================================
FROM python:3.12-slim-bookworm AS builder

WORKDIR /app

# 安装系统依赖（仅构建时需要）
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# 先复制依赖文件（利用 Docker layer cache）
COPY requirements.txt .
RUN pip install --no-cache-dir --user -r requirements.txt

# ============================================================
# Stage 2: Runtime
# ============================================================
FROM python:3.12-slim-bookworm AS runtime

# 安全：创建非 root 用户
RUN groupadd -r appuser && useradd -r -g appuser appuser

WORKDIR /app

# 从 builder 复制已安装的依赖
COPY --from=builder /root/.local /home/appuser/.local

# 复制应用代码
COPY --chown=appuser:appuser src/ ./src/

# 确保 PATH 包含用户安装的包
ENV PATH=/home/appuser/.local/bin:$PATH
ENV PYTHONUNBUFFERED=1

# 切换到非 root 用户
USER appuser

EXPOSE 8000

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
    CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"

CMD ["uvicorn", "src.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 模板 — Node.js / Express

```dockerfile
# ============================================================
# Stage 1: Build
# ============================================================
FROM node:22-alpine AS builder

WORKDIR /app

COPY package.json package-lock.json ./
RUN npm ci --production=false

COPY . .
RUN npm run build

# ============================================================
# Stage 2: Runtime
# ============================================================
FROM node:22-alpine AS runtime

RUN addgroup -S appgroup && adduser -S appuser -G appgroup

WORKDIR /app

COPY --from=builder /app/package.json /app/package-lock.json ./
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist

ENV NODE_ENV=production

USER appuser

EXPOSE 3000

HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
    CMD wget --quiet --tries=1 --spider http://localhost:3000/health || exit 1

CMD ["node", "dist/index.js"]
```

### 约束

| 约束 | 理由 |
|------|------|
| 基础镜像不使用 `:latest` | 版本漂移导致不可复现 |
| 必须创建非 root 用户 | 安全最佳实践 |
| 必须包含 HEALTHCHECK | 便于编排系统感知服务状态 |
| `apt-get` 后必须 `rm -rf` | 减小镜像体积 |
| `npm ci` 而非 `npm install` | 严格按 lock 文件安装 |

## Step 3: docker-compose.yml 生成

```yaml
# docker-compose.yml
# Generated by: fullstack-deploy skill
# Project: <project_name>
# Date: 2026-07-25

version: "3.9"

services:
  app:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: ${PROJECT_NAME:-app}
    ports:
      - "${APP_PORT:-8000}:8000"
    environment:
      - DATABASE_URL=postgresql://${DB_USER:-app}:${DB_PASSWORD}@db:5432/${DB_NAME:-app}
      - REDIS_URL=redis://cache:6379/0
      - SECRET_KEY=${SECRET_KEY}
    env_file:
      - .env
    depends_on:
      db:
        condition: service_healthy
      cache:
        condition: service_started
    restart: unless-stopped
    networks:
      - app-network
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
      interval: 30s
      timeout: 10s
      retries: 3

  db:
    image: postgres:16-alpine
    container_name: ${PROJECT_NAME:-app}-db
    environment:
      POSTGRES_USER: ${DB_USER:-app}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: ${DB_NAME:-app}
    volumes:
      - pgdata:/var/lib/postgresql/data
    restart: unless-stopped
    networks:
      - app-network
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER:-app} -d ${DB_NAME:-app}"]
      interval: 10s
      timeout: 5s
      retries: 5

  cache:
    image: redis:7-alpine
    container_name: ${PROJECT_NAME:-app}-cache
    volumes:
      - redisdata:/data
    restart: unless-stopped
    networks:
      - app-network

volumes:
  pgdata:
  redisdata:

networks:
  app-network:
    driver: bridge
```

### 约束
- 数据库密码**不从 YAML 硬编码**，使用 `${VAR}` 环境变量引用
- `depends_on` 配合 `condition: service_healthy`（不依赖启动顺序）
- 数据库数据持久化用 named volume（不用 bind mount）
- 所有服务必须在同一个自定义 network 中

## Step 4: CI 配置生成

### GitHub Actions 模板

```yaml
# .github/workflows/ci.yml
# Generated by: fullstack-deploy skill

name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  PYTHON_VERSION: "3.12"
  NODE_VERSION: "22"

jobs:
  lint:
    name: Lint & Type Check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: pip

      - name: Install dependencies
        run: pip install ruff mypy

      - name: Lint with ruff
        run: ruff check .

      - name: Type check with mypy
        run: mypy src/

  test:
    name: Test
    runs-on: ubuntu-latest
    needs: lint
    services:
      postgres:
        image: postgres:16-alpine
        env:
          POSTGRES_USER: test
          POSTGRES_PASSWORD: test
          POSTGRES_DB: test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: pip

      - name: Install dependencies
        run: pip install -r requirements.txt -r requirements-dev.txt

      - name: Run tests
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/test
        run: pytest -v --cov=src --cov-report=xml

      - name: Upload coverage
        uses: codecov/codecov-action@v4
        with:
          file: ./coverage.xml

  build:
    name: Build Docker Image
    runs-on: ubuntu-latest
    needs: test
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v4

      - name: Build image
        run: docker build -t ${{ github.repository }}:${{ github.sha }} .

      - name: Scan for vulnerabilities
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: ${{ github.repository }}:${{ github.sha }}
          format: table
          exit-code: 1
          severity: CRITICAL,HIGH
```

### 安全约束（core/governance.md §1）

| 规则 | 实现 |
|------|------|
| `.env` 在 `.gitignore` 中 | `.dockerignore` 不含 `.env.example` |
| `.env.example` 可提交 | 不含真实密钥，只有占位符 |
| CI 中密钥通过 GitHub Secrets | 不硬编码在 CI YAML 中 |
| Dockerfile 不 COPY `.env` | 运行时通过 `env_file` 或 `--env-file` 注入 |

## 禁止行为

| 禁止 | 原因 |
|------|------|
| Dockerfile 中硬编码 `SECRET_KEY=xxx` | P0 安全违规 |
| docker-compose.yml 中直接写数据库密码 | 应使用 `${VAR}` 环境变量 |
| 使用 `:latest` 标签 | 不可复现 |
| CI 中 git clone 整个历史 | 浅克隆 `fetch-depth: 1` |
| COPY 整个项目目录包括 `.env` | 敏感信息泄露 |
| 不生成 HEALTHCHECK | 编排系统无法判断服务状态 |
