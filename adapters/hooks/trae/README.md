# AgentSeed Hook - trae

Auto-generated by agentseed platform import.

## What this does

Intercepts AI tool calls before execution and checks them against AgentSeed governance rules.

Calls decide() from adapters/hooks/shared/check.py:
- Deny: block dangerous operations
- Require Approval: ask user first
- Warn: allow with warning
- Allow: pass through silently

Fail-open: if hook crashes, tool call is allowed.

## Installation

1. Copy hooks.json.template to your hooks config
2. Update path to pre_tool_use.py
3. Restart your AI tool
